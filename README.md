# Guild Bank Viewer (addon)

Export your bank character's bank as an import string for [guildbankviewer.com](https://guildbankviewer.com).

Supports **Classic Era, Season of Discovery and Anniversary** (Interface 11508/11509).

## Use

1. Open your bank in game. The addon remembers what it sees.
2. Click **Export** on the bank window, or type `/gbv` (works afterwards too, using the last saved snapshot).
3. Press `Ctrl+C` on the selected text, then paste it into **Import** on your bank page at guildbankviewer.com.

Only the 28 main bank slots are exported, not bank bags.

## Install

CurseForge / Wago (links will be added on release), or download a zip from
[Releases](../../releases) and extract `GuildBankViewer` into `World of Warcraft/_classic_era_/Interface/AddOns/`.
